# The design-locked files (X5). One list, read by scripts/check-design-lock.mjs
# and pinned by scripts/checkDesignLock.test.ts.
#
# These are the files behind the screens CLAUDE.md's "Design lock" sections
# name. A commit that changes any of them must carry a `Founder-Approved:`
# trailer naming the founder's decision, for example
#
#     Founder-Approved: Navigation Panel GO-W1, 2026-10-07
#
# or the guard (`npm run check:design-lock`, in CI and in scripts/local_ci.sh)
# fails the diff. A path ending in "/" locks every file under it. Test files
# (*.test.ts, *.test.tsx) are never locked: a test pins a screen, it is not one.
#
# Adding a screen to a lock = adding its files here, in the same commit as the
# CLAUDE.md section that locks them.
