# Moment → Intervention

> **Label: Reference.** The founder's handwritten notes (21 November 2026), four pages. This is the frontend that was built from them. Nothing here calls a production backend.

## Value

Spot a moment when the speaker is not engaged. That kills presentations and sales. Once their baseline is known, the aim is positive engagement, not negative engagement: supportive arousal, rather than arousal that eats them up. When the arousal is supportive, help them say it clearly, then make that clear line stand out with vocal intonation, in time with the presentation, aligned with the context and with the listener's specific need. They have the feedback, they have trained, they know what to look at, and they know they are ready. Stress goes down. Efficacy goes up.

## What a host sets

Saved on this device (`wlp-moment-config`). Defaults:

| Setting | Default |
| --- | --- |
| Recording | 5 minutes. The control offers 1 to 5. Longer than 5 is stored as 5. |
| Engagement questions | Both on: "Are you engaged?" and "Is the arousal supportive, or is it eating you up?" |
| Normal-voice sample | On. |
| Checkpoints 1–5 | All on. |
| Visitors start on the baseline | Off, until the host turns it on and saves. Try on the home tiles stays the chat it is today until then. |

Checkpoint interventions:

1. Is the speaker engaged? → Baselines. Subjective: arousal up or down.
2. Is the speaker above their own mean arousal? → Pace, AI audio. Supportive arousal, or arousal that eats you up.
3. Clarity of the utterance → Rewrite.
4. Meritoric value → Rewrite. Yes or no.
5. Prosody-related tunings → Video, AI audio.

Moments (engagement, arousal, clarity, context) and interventions (baselines, rewrite, AI audio, pace, video, praise) are separate patterns. A mapping fires when the pattern reaches its threshold. Intensity is how strongly it fires. Mappings are independent and can fire together. The four match shapes on the notes are: they climb together; one dips, then they meet; they meet late, offset; quiet, then a spike.

The host's screen does not show a visitor's answers or a reading.

## What a speaker meets

Baseline, then the recording, then one card per checkpoint that is on.

The baseline asks the questions the host left on, then (if the sample is on) "Keep a sample of my normal voice". The sound is not stored. The tab only remembers that a sample was given.

The recording step states the limit and that a shorter whole presentation should hold every point. Record does not upload anything.

The results are a **placeholder**. The line on screen is: "Placeholder. This is not a reading of the recording. No model ran." The stand-in pattern is fixed (engagement 70, arousal 80, clarity 40, context 55, shape "they climb together"). It is not a measurement. With the defaults, baselines, pace, AI audio and video show on their checkpoints. Rewrite stays quiet because clarity is under its usual threshold. Praise is not named on a checkpoint, so it shows under "Also fired". Delete my data sits in the bottom bar.

Near the results: "This feedback is generated by AI." and "Only you can see this. The host of this chat cannot."

"Delete my data" removes the speaker's tab store (`wlp-moment-speaker` in sessionStorage). The host's settings stay.

## API contract (not called)

These routes are the shape a later backend would take. This frontend does not call them.

`POST /v2/moment/baseline`

```json
{ "chatId": "own-…", "answers": { "engaged": "Not engaged", "valence": "Supportive" }, "voiceSample": true }
```

The voice sample is a boolean here. A later route may accept audio. The response is `{ "ok": true }`. The server stores it only for that speaker.

`POST /v2/moment/recording`

```json
{ "chatId": "own-…", "limitSeconds": 300 }
```

The body is the audio, at most `limitSeconds` (never above 300). Response: `{ "recordingId": "…" }`.

`POST /v2/moment/analysis`

```json
{ "recordingId": "…" }
```

Response, one row per checkpoint that is on:

```json
{
  "placeholder": false,
  "checkpoints": [
    { "id": "2", "fired": [{ "intervention": "pace", "moment": "arousal", "intensity": 70, "shape": "climb" }], "quiet": [] }
  ]
}
```

`placeholder: true` means the server did not run a model. The screen must keep the placeholder line.

`DELETE /v2/moment/speaker`

Deletes that speaker's baseline, recording and analysis. Response `{ "ok": true }`. No host, admin or employer route reads these rows or an aggregate of them.
