# Competitor research: conversational and iterative chat builders

Research date: 17 Nov 2026 (Europe/Warsaw). This brief is for the Willpower Lab Chat Builder, modelled on the lab's Presentation Builder (Brief → Plan → Slides → Look stepper, versions and undo, orange tappable quoted suggestions, mic composer, and a list view of the built config).

**Method.** Every product claim below is taken from official documentation or help-centre pages fetched or searched on this date. I did not sign into the products, so I did not capture in-app screens that sit behind a login. If a capability is not described in the official pages I opened, I say so rather than infer it. Community posts are not used as facts.

**What "working bot" means here.** For consumer builders it means a chat you can talk to immediately after create or publish. For support / voice platforms it means a testable preview or a test call, not a production rollout.

---

## Top 4 for design and simplest navigation

Ranked for a *mobile, voice-first, tap-or-talk, iterative* builder that a 12-year-old could finish, not for enterprise depth.

### 1. Gamma Agent (create-with-agent flow)

Not a chatbot product, but the strongest design reference for "talk, answer a few taps, approve a plan, watch it get built, then iterate in the same chat." Official help describes a conversation-first create flow: one prompt, a handful of questions with **tappable options** and **Decide for me**, a plan you review before anything is built, a live narrated build, and later edits in plain language that change only what you asked. On mobile, edits are done through Agent and **voice dictation is in every chat box**, with a review-before-send transcript. Express mode skips questions when you already know what you want.

Sources: [How do I create with Agent in Gamma?](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma), [What is Gamma and how do I get started?](https://help.gamma.app/en/articles/18343586-what-is-gamma-and-how-do-i-get-started), [Does Gamma have a mobile app?](https://help.gamma.app/en/articles/11016450-does-gamma-have-a-mobile-app).

### 2. OpenAI GPT Builder (Create vs Configure)

The clearest *bot-specific* hybrid. Official help: open the builder, then choose a **conversational builder** ("describe what you want, and ChatGPT will help draft the GPT") or a **configuration view** (edit the fields directly). OpenAI Academy names these the **Create** and **Configure** tabs and notes that Configure is usually faster when you already know the settings. Configure holds name, description, instructions, conversation starters, knowledge files, a recommended model, capabilities, and actions. A **Preview** chat sits beside the setup. Changes auto-save as a draft; Create / Update publishes them. Version history is in the ••• menu and can restore earlier versions.

Caveats from the same official pages: creation and editing are **web-only** (mobile apps can use GPTs, not create them). New GPT creation is unavailable on personal ChatGPT accounts, and OpenAI is retiring custom GPTs in favour of plugins (Enterprise creation cutoff 26 Oct 2026; standard retirement 11 Dec 2026). The interaction model is still the best published example of "talk to draft it, then see and edit the list."

Sources: [Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts), [Four GPT templates for small businesses](https://academy.openai.com/en/public/clubs/small-business-ipf4m/resources/four-gpt-templates-for-small-businesses-2026-03-05).

### 3. Lovable (Chat / Plan / Build)

The strongest iterative "talk to build, see the result, undo safely" loop in a production builder. Official docs: you describe what you want in natural language; a project holds **project chat, preview, code, and version history**. The project chat has three modes you can switch at any time, with the conversation carrying across them: **Chat** (discuss, no plan or code changes), **Plan** (investigate and write a plan you edit and approve before building), **Build** (implement and verify). Every change creates a version automatically. You can preview a version, revert the project to it, undo the latest edit, or edit a past message and **Revert and resend**. A Details / Timeline view shows the steps while it works.

Caveats: this is a full-stack *app* builder billed in credits, not a dedicated bot-config form. Official docs I opened do not describe a mic in the project composer.

Sources: [Welcome to Lovable](https://docs.lovable.dev/introduction/welcome), [Implement changes in Build mode](https://docs.lovable.dev/features/agent-mode), [Revert and restore your project with version history](https://docs.lovable.dev/features/projects/history).

### 4. Landbot ("Build it for me")

The best *bot-native* version of describe-then-see-the-flow. Official help: you can describe an agent in your own words (max 1,000 characters) and Landbot generates a working flow; or start from a template or a blank canvas; or have an AI assistant build it through the Landbot MCP / Plugin. The result always opens in the same visual builder. You can test it, edit any block, and use **Build it for me** again mid-flow to add a path. The builder has undo/redo and a clock-icon version history with Select then Restore. End-user navigation is button-first: a Buttons block offers tappable options and can branch, or share an "Any of the above" path.

This is closer to a 12-year-old's "see the list of how it's done" than Studio canvases from Botpress or Voiceflow, while still being a real chatbot product.

Sources: [How to build an agent in Landbot](https://help.landbot.io/article/jmyarmlbih-getting-started-build-a-bot), [Build it for me!](https://help.landbot.io/article/a6l84s29zv-build-it-for-me), [Builder Interface Tour](https://help.landbot.io/article/391rg1t7wz-builder-interface-tour).

**Honourable mentions (not in the top 4).**

- **Character.ai** — simplest *mobile form* to a live character ("five minutes to a live Character"), with **Write for me** greetings and a character voice, but creation is a form, not a talk-to-build loop. Source: [Creating a Character: Quickstart Guide](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89).
- **v0** — very close to Lovable: describe in a chat, review a live preview, iterate, restore versions. Source: [v0 Quickstart](https://v0.app/docs/quickstart), [Versions](https://v0.app/docs/versions).
- **Poe prompt bots** — a short mobile-capable form with a base-bot (model) picker and optional **Suggest replies**. Source: [How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot).

## Patterns to adopt (12 patterns)

These are concrete patterns for a mobile, voice-first, tap-binary Chat Builder that a 12-year-old can use, mapped onto the lab's Presentation Builder. Each pattern cites the product that demonstrates it.

1. **Talk to draft it, always show the list.** Keep a conversational builder and a configuration list in the same session, the way GPT Builder splits **Create** and **Configure**. Talking should fill the list; the list should stay visible and editable. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Academy templates](https://academy.openai.com/en/public/clubs/small-business-ipf4m/resources/four-gpt-templates-for-small-businesses-2026-03-05).)

2. **A short Brief of tappable questions, with "you decide" on every one.** Follow Gamma: a handful of questions, each with tappable options *and* a typed/spoken custom answer, plus **Decide for me** so nothing is a dead end. Skip remaining questions if the first answer already covers them. ([Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma).)

3. **Plan before build, then say go.** Gamma will not start building until you approve the plan. Lovable **Plan** mode writes a plan you edit and approve before **Build** changes anything. This is the Presentation Builder's Plan step. ([Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma); [Build mode / Plan mode](https://docs.lovable.dev/features/agent-mode).)

4. **A numbered list of how the chat is built, always openable.** The current config should look like a stable, scrollable list (name, they send, style, model, knowledge, first line…), not only a buried form. GPT Configure, Claude's project knowledge panel, Landbot's generated flow, and Gamma's numbered thumbnail strip all keep the artefact beside the chat. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Claude projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects); [Landbot build](https://help.landbot.io/article/jmyarmlbih-getting-started-build-a-bot); [Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma).)

5. **Versions on every meaningful change, plus one-tap undo.** Auto-save a version (Lovable, v0 when code updates, GPT drafts + version history). Offer Undo for the last step and Restore for an earlier version, without destroying the conversation. Landbot and Voiceflow restore from a clock / history icon; Vapi publishes immutable versions and restores by creating a new current version. ([Lovable version history](https://docs.lovable.dev/features/projects/history); [v0 Versions](https://v0.app/docs/versions); [Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Landbot Builder Interface Tour](https://help.landbot.io/article/391rg1t7wz-builder-interface-tour); [Voiceflow version history](https://www.voiceflow.com/docs/documentation/deploy/environments/version-history); [Vapi assistant versioning](https://docs.vapi.ai/assistants/versioning/versioning-assistants).)

6. **Orange (or otherwise obvious) tappable suggestion chips.** GPT conversation starters, Poe **Suggest replies**, and Gamma's tappable question options all reduce typing. In the Chat Builder these should be the Presentation Builder's orange quoted suggestions: short, one-tap, and still overridable by voice or text. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Poe prompt bots](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma).)

7. **Mic-first composer, review the transcript, typing always works.** Gamma's mobile app puts voice dictation in every chat box: tap the mic, speak, review/edit the transcript, then send. Official GPT Builder pages do not document voice inside Create (creation is web-only). Keep typing and tapping as equals of voice. ([Gamma mobile app](https://help.gamma.app/en/articles/11016450-does-gamma-have-a-mobile-app); [Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts) for the web-only limit.)

8. **Binary taps for decisions; text only when needed.** Typebot Buttons and Landbot Buttons split the path on a tap, including an "Other" / free-text escape. Intercom Fin offers five named tones and three answer lengths as tappable choices with a live preview. The Chat Builder should default to two clear options (Yes/No, Try it / Keep mine, Record / Type) and only open a text box when the user picks "something else." ([Typebot Buttons](https://docs.typebot.com/editor/blocks/inputs/buttons); [Landbot build](https://help.landbot.io/article/jmyarmlbih-getting-started-build-a-bot); [Fin tone of voice and answer length](https://www.intercom.com/help/en/articles/13177409-customize-fin-ai-agent-tone-of-voice-and-answer-length).)

9. **A stepper across the top, with a fast path.** Presentation Builder already uses Brief → Plan → Slides → Look. Gamma offers Plan vs Express; Lovable offers Chat / Plan / Build. Landbot's top bar is Build / Design / Settings / Launch. Keep four or fewer named steps, and an Express / "just build it" skip. ([Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma); [Lovable Build mode](https://docs.lovable.dev/features/agent-mode); [Landbot Builder Interface Tour](https://help.landbot.io/article/391rg1t7wz-builder-interface-tour).)

10. **Preview the chat beside the builder, then Keep / Next.** GPT Preview, Botpress's post-setup preview, ElevenLabs **Test AI agent**, Vapi **Talk** (and **Chat** for the unsaved draft), and Fin Preview all test before going live. The first bubble should be the thing the user just chose, matching the lab's existing "row as first bubble" rule. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Botpress Quickstart](https://botpress.com/docs/studio/get-started/quick-start/); [ElevenLabs Agents Quickstart](https://elevenlabs.io/docs/eleven-agents/quickstart); [Vapi assistants quickstart](https://docs.vapi.ai/assistants/quickstart) and [versioning](https://docs.vapi.ai/assistants/versioning/versioning-assistants); [Fin explained](https://www.intercom.com/help/en/articles/7120684-fin-ai-agent-explained).)

11. **Targeted iterative edits, not a full rebuild.** Gamma: tell the agent what feels off in your own words; revisions are targeted and it shows what changed; restyle keeps content, regenerate starts over. Lovable: send follow-ups mid-build; undo latest edit if it went wrong. The Chat Builder should name the row it changed and leave the rest alone. ([Create with Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma); [Lovable Build mode](https://docs.lovable.dev/features/agent-mode).)

12. **"Write this for me" on any hard field, then you keep or rewrite it.** Character.ai **Write for me** on greetings; Voiceflow **generate** on the global agent description; Vapi **Generate** on the system prompt (describe the change, review, Accept). Use this for name, first line, style, and instructions so a 12-year-old never faces a blank box. ([Character.ai Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89); [Voiceflow chat agent quick start](https://www.voiceflow.com/docs/courses/chat-agent-quick-start); [Vapi assistants quickstart](https://docs.vapi.ai/assistants/quickstart).)

13. **Simple capability chips instead of a settings maze.** GPT Capabilities are on/off (web search, image generation, canvas, code interpreter, apps). Fin tone and answer length are short named choices with a preview. Poe picks a **base bot**. Vapi picks a **model preset** (Balanced, High Intelligence, Ultra Fast) that bundles transcriber, model, and voice. Expose model, they-send (record / type / photo / file), and style as chips; bury API keys and custom code behind an Advanced row. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Fin tone of voice](https://www.intercom.com/help/en/articles/13177409-customize-fin-ai-agent-tone-of-voice-and-answer-length); [Poe prompt bots](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [Vapi assistants quickstart](https://docs.vapi.ai/assistants/quickstart).)

14. **A first line / greeting that starts the experience.** Character.ai, Poe, ElevenLabs, and Vapi all treat the opening line as a first-class field. That maps to the lab rule that the chosen row becomes the first bubble. Offer up to a few alternate first lines (Character.ai allows five extra greetings plus an AI-greeting toggle). ([Character.ai Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89); [Poe prompt bots](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [ElevenLabs Agents Quickstart](https://elevenlabs.io/docs/eleven-agents/quickstart); [Vapi assistants quickstart](https://docs.vapi.ai/assistants/quickstart).)

15. **Draft versus live, and a very short path to a testable chat.** Auto-save drafts (GPT, Vapi) and require an explicit Publish only when going live (Landbot, Voiceflow, Vapi). Official "time to first working preview" targets to beat: Voiceflow "3 minutes or less," Character.ai "five minutes," ElevenLabs "as little as 5 minutes," Lovable "about ten minutes" to publish. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Vapi versioning](https://docs.vapi.ai/assistants/versioning/versioning-assistants); [Landbot Builder Interface Tour](https://help.landbot.io/article/391rg1t7wz-builder-interface-tour); [Voiceflow chat agent quick start](https://www.voiceflow.com/docs/courses/chat-agent-quick-start); [Character.ai Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89); [ElevenLabs Agents Quickstart](https://elevenlabs.io/docs/eleven-agents/quickstart); [Lovable welcome / quick start](https://docs.lovable.dev/introduction/welcome).)

## Product notes

For each product: how creation flows, how the current state is shown, versions / undo, voice input, tap / quick-reply chips, steps to a working bot, what is configurable, and design notes. "Not documented in the official pages I opened" means I am not claiming the feature is absent from the product, only that I could not source it here.

### OpenAI GPT Builder

- **Flow:** Hybrid. Conversational builder or configuration view / Create vs Configure tabs. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts); [Academy templates](https://academy.openai.com/en/public/clubs/small-business-ipf4m/resources/four-gpt-templates-for-small-businesses-2026-03-05).)
- **Current state:** Configure shows the fields (name, description, instructions, conversation starters, knowledge, recommended model, capabilities, actions). Preview is a test chat. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)
- **Versions / undo:** Edits auto-save as a draft. Create (new) or Update (existing) applies the draft. Version history is under ••• and can restore an earlier version; restoring a GPT that uses actions may require reconfiguring authentication. Duplicate / copy link / delete live in the same menu. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)
- **Voice input:** Official create/edit pages describe a web builder only. "Mobile apps support using GPTs but do not support creating them." I found no official statement that the Create tab accepts voice. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)
- **Chips:** Conversation starters are example prompts shown when someone opens the GPT. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)
- **Steps to a working bot:** Open Explore GPTs or chatgpt.com/gpts → Create → describe in Create or fill Configure → test in Preview → Create / Update. Academy lists six core steps, including capability toggles and visibility. ([Academy templates](https://academy.openai.com/en/public/clubs/small-business-ipf4m/resources/four-gpt-templates-for-small-businesses-2026-03-05).)
- **Configurable:** Name, description, conversation starters, instructions, knowledge (up to 20 files, 512 MB each; common document / spreadsheet / image / text / code types; some types need Code Interpreter), recommended model (users may still switch), capabilities (web search, image generation, canvas, Code Interpreter & Data Analysis, apps), actions (external APIs; a GPT can use apps *or* actions, not both), sharing. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)
- **Design notes:** The Create / Configure / Preview split is the pattern to copy. Availability is restricted and the product is on a documented retirement path toward plugins, so treat it as a UX source, not a platform to depend on. ([Creating and editing GPTs](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).)

### Claude Projects

- **Flow:** Form, then chat inside the project. Not a conversational "build the bot" wizard. Click + New Project, give a name and description (Claude does **not** get those details), then set project instructions and upload knowledge. ([How can I create and manage projects?](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects).)
- **Current state:** Project knowledge sits on the right of the project main page. Instructions are a separate "Set project instructions" panel. Chats do not share context unless the information is in the project knowledge base. ([How can I create and manage projects?](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects).)
- **Versions / undo:** Official project-management help I opened covers archive, unarchive, delete, and sharing, not a version history of instructions. Do not claim undo / versions from these pages.
- **Voice input:** Not described on the project-management page I opened.
- **Chips:** Not described as a project-setup pattern on that page.
- **Steps to a working project:** Projects → + New Project → name (and description) → optional visibility / tags → set instructions → add knowledge → start a chat. Free users can create at most five projects; projects are available to all users including free accounts. ([How can I create and manage projects?](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects).)
- **Configurable:** Project instructions (tone, behaviour, workflow); knowledge (documents, text, code; paid plans can switch to RAG near the context-window limit); sharing and roles (view / edit) on Team or Enterprise; project memory, with an option to turn off "Use account memory." Name and description are for humans, not for Claude. Account-wide instructions are a separate Settings feature. ([How can I create and manage projects?](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects); [Understanding Claude's personalization features](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features).)
- **Design notes:** Very simple, but it is a *workspace with memory and files*, not a published custom bot. The right-hand knowledge + instructions panel is a good "always-visible config" reference. Model choice is not documented as a project setting on the pages I opened.

### Poe bot creator

- **Flow:** Form on the web or in the mobile app (sidebar → Create a bot, or poe.com/create_bot). Official creator docs also list other paths: Prompt Bots, Server Bots, Script Bots ("Python-based bots hosted on Poe through vibe-coding"), Canvas Apps, and API Bots that bring any model via a Chat Completions or Responses endpoint. ([How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [Poe Creator Guide](https://creator.poe.com/docs); [Poe FAQs](https://help.poe.com/hc/en-us/articles/19944206309524-Poe-FAQs).)
- **Current state:** A single create / edit form (picture, name, description, base bot, prompt, optional knowledge, greeting, advanced toggles). After create, open the bot and choose Edit bot. ([How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [Poe FAQs](https://help.poe.com/hc/en-us/articles/19944206309524-Poe-FAQs).)
- **Versions / undo:** Not described on the prompt-bot how-to or the FAQ pages I opened. You can return later and update the name and other fields.
- **Voice input:** Not described as a builder input on those pages. The mobile app can create a bot, which matters for navigation, but that is not the same as voice-first building.
- **Chips:** Optional **Suggest replies** shows LLM-generated reply options after a bot response. ([How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot).)
- **Steps to a working bot:** Open create_bot → picture / name / description → pick a base bot and write a prompt → optional knowledge, greeting, advanced options → Create bot → land on the bot page and chat. Name is 4–20 characters and is prefilled with a random id you can keep. ([How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot).)
- **Configurable:** Base bot (the underlying model), prompt (optionally visible on the profile), knowledge sources from files or raw text (official how-to: major text formats .txt / .pdf / .docx / .html; 5 GB or 30 million characters combined; optional "Cite sources"), greeting, suggest replies, markdown rendering, custom temperature, "Optimize prompt for Previews," public vs private ("Bot publicly accessible"). Server / script / API bots add custom code or an external model endpoint. Monetization and cost-coverage docs exist on the creator platform but I did not pull pricing tables for this brief. ([How to create a prompt bot](https://creator.poe.com/docs/prompt-bots/how-to-create-a-prompt-bot); [Poe Creator Guide](https://creator.poe.com/docs); [Poe FAQs](https://help.poe.com/hc/en-us/articles/19944206309524-Poe-FAQs).)
- **Design notes:** One of the few official mobile create paths. The form is short and model choice is first-class. It is not a talk-to-build loop unless you use Script Bot Creator / App Creator (those are listed as products at poe.com/Script-Bot-Creator and poe.com/App-Creator in the [changelog](https://creator.poe.com/changelog); I did not open a dedicated how-to for their conversational UI). **Knowledge-base status:** the official how-to I fetched still documents knowledge bases. I did not find a deprecation notice in the official changelog pages I reviewed, so I am not treating third-party reports as fact.

### Character.ai character creation

- **Flow:** Form, express route, mobile and web. Mobile: tap + at the bottom, then Character. Web: +Create in the left menu, then Character. Official copy: "five minutes to a live Character." ([Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89).)
- **Current state:** Profile fields (name, avatar, tagline, description, greeting, voice) plus an optional Character Definition. Definition is freeform, 0–32,000 characters, read top to bottom. Structured dialogue helpers sit under the field (+ User message, + Character message, + End of dialog). ([Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89); [Character Definition](https://support.character.ai/hc/en-us/articles/50609183646875-5-Character-Definition).)
- **Versions / undo:** Not described on the quickstart or definition pages I opened. Iteration is "chat, then tighten the Definition." Official refining guidance lives at [Refining and Testing your Character](https://support.character.ai/hc/en-us/articles/50609303987099-6-Refining-and-Testing-your-Character) (I used the official URL; I did not fetch the full body in this pass).
- **Voice input:** The create flow includes **Choose a Voice**: suggested voice, library, or a 3–15 second clip. That is the *character's* voice, not documented here as dictation in the creator form. ([Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89).)
- **Chips / helpers:** **Write for me** generates greeting variations; up to five additional greetings; optional **AI Greeting for New Chats**. Tags help discovery. Visibility is Public / Unlisted / Private. ([Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89).)
- **Steps to a working character:** Start flow → name → avatar (upload or Generate) → voice → greeting → tags → visibility → optional tagline / description / definition → Create and start chatting. Definition is optional at creation. ([Quickstart](https://support.character.ai/hc/en-us/articles/50608869548699-2-Creating-a-Character-Quickstart-Guide-%CF%89).)
- **Configurable:** Name, avatar, voice, greeting(s), tags, visibility, tagline and description (user-visible), Character Definition (optionally visible) for identity, personality, dialogue examples, behavioural rules. I did not find a model or pricing picker in the official create guide.
- **Design notes:** Best-in-class *short mobile form*. "Write for me," optional depth, and a live chat immediately after Create are the pieces to steal. It is not a conversational builder, and it does not expose tools, APIs, or model choice in the pages I opened.

### Botpress (Autonomous agent setup / Studio)

- **Flow:** Hybrid. Skip goes to a blank Studio tutorial. Studio then uses a visual workflow: by default Main Workflow is Start Node → Autonomous Node → End Node. Home is a shortcut into the Autonomous Node when that path is in place. ([Quickstart](https://botpress.com/docs/studio/get-started/quick-start/); [Workflows](https://botpress.com/docs/tutorial/basics/custom-logic/workflows/); [Autonomous Node](https://botpress.com/docs/studio/concepts/nodes/autonomous-node/); [Studio Home](https://botpress.com/academy-lesson/studio-ui-home).)

- **Voice input:** Not described as a Studio builder input on the pages I opened.
- **Chips:** Not a first-run chip pattern in those pages. End-user webchat can be styled separately ([Quickstart](https://botpress.com/docs/studio/get-started/quick-start/)).
- **Steps to a working bot:** Start building / Build my agent → follow the setup → preview a bot "trained on your sources and styled to match your brand" → optional fine-tune in Studio → deploy via Webchat or a channel. ([Quickstart](https://botpress.com/docs/studio/get-started/quick-start/).)
- **Configurable:** Instructions / persona, knowledge bases, tools, variables (read and optional write), sub-workflows, exit conditions, model override per Autonomous Node (otherwise Bot Settings), LLMz version, webchat appearance, channels. Docs recommend a high-performing model, "roughly equivalent to … GPT-4.1," for Autonomous Nodes. ([Autonomous Node](https://botpress.com/docs/studio/concepts/nodes/autonomous-node/); [Studio Home](https://botpress.com/academy-lesson/studio-ui-home).)
- **Design notes:** The first-run wizard plus a later Studio is a sensible "simple now, deep later" split. Home as a single place for role, instructions, knowledge, and tools is good. The canvas itself is more than a 12-year-old needs for a first chat.

### Voiceflow

- **Versions / undo:** Every publish records a version. Open history from the history icon next to an environment in Settings → Environments. ([Version history](https://www.voiceflow.com/docs/documentation/deploy/environments/version-history).)
- **Voice input:** Not described as a builder input on the pages I opened. Voiceflow is historically voice-and-chat capable; I am not inferring a mic in the current create flow from that history.
- **Chips:** Workflows can include "scripted messages, buttons, conditions, and other non-AI steps." ([Building an agent](https://www.voiceflow.com/docs/documentation/build/overview).)
- **Steps to a working bot:** Official heading is "Build and launch your first chat agent in 3 minutes or less": create project → generate persona → optional knowledge (docs, URL, or pasted text) → Publish → try the widget in the editor. - **Configurable:** Global prompt and instructions; playbooks; workflows; knowledge (URLs, sitemaps, documents, plus connectors such as Zendesk, Shopify, Kustomer, Salesforce); tools (API, JavaScript functions, integrations, MCP, global and system tools); variables; secrets; framework choice. ### Typebot

- **Flow:** Visual editor, not a conversational builder in the official docs I opened. Typebot is a "fair source chatbot builder" for conversational apps/forms and AI chats. You arrange **blocks** in a **Graph**, contained in titled groups, and connect them with edges. A block without an outgoing edge stops the conversation; the editor does not warn visually. ([Welcome](https://docs.typebot.com/get-started/introduction); [Creating a typebot](https://docs.typebot.com/get-started/overview); [Graph](https://docs.typebot.com/editor/graph); [Blocks overview](https://docs.typebot.com/editor/blocks/overview).)
- **Current state:** The graph *is* the current state: bubbles, inputs, logic, integrations. ([Blocks overview](https://docs.typebot.com/editor/blocks/overview).)
- **Versions / undo:** Not described on the overview, graph, or blocks pages I opened.
- **Voice input:** Not a builder mic in those pages. There are OpenAI **Create speech** and **Create transcription** *blocks* for the running bot (speech URLs expire after 7 days). ([OpenAI integration](https://docs.typebot.com/editor/blocks/integrations/openai).)
- **Chips:** **Buttons** input: single-choice (each choice can start a path; a Default path is supported) or multiple-choice; dynamic lists from a variable; display conditions; internal values; an official how-to for an "Other" button that leads to a Text input. ([Buttons](https://docs.typebot.com/editor/blocks/inputs/buttons).)
- **Steps to a working bot:** Official get-started overview points at a short video rather than a written step count, so I am not inventing a number. After the graph is connected, you deploy the bot (deploy docs exist; I did not fetch a publish checklist here). ([Creating a typebot](https://docs.typebot.com/get-started/overview); [Welcome](https://docs.typebot.com/get-started/introduction).)
- **Configurable:** Full flow logic; OpenAI / Anthropic integrations with model selection, instructions, dialogue history, tools / functions (server-side JavaScript with `return` and `setVariable`), built-in tools on Ask Model (file search, web search, code interpreter), plus speech and transcription. This is how Typebot adds models, tools, and custom code — block by block, often with the builder's own OpenAI account and quota. ([OpenAI integration](https://docs.typebot.com/editor/blocks/integrations/openai).)
- **Design notes:** Excellent *end-user* tap navigation, weak *creator* conversation. Steal Buttons and "Other → type," not the canvas-as-IDE, for a 12-year-old builder.

## What this means for the Willpower Lab Chat Builder

The Presentation Builder already matches the best create loop in this set (Gamma's Plan + tappable questions + mic + versions). The Chat Builder should use that same loop, and borrow bot-specific pieces from GPT Builder (Create + visible Configure list + Preview), Landbot (generated flow you can walk and restore), and Vapi / Character.ai (first line, "write this for me," simple presets).

A first path that stays faithful to the research, without dropping depth, would look like this:

1. **Brief** — talk or type what the chat is for. A few tappable questions with "you decide."
2. **Plan** — a short numbered plan of the chat (who it is for, first line, they send, style, model preset, knowledge). Approve, or Express-skip.
3. **Build** — the plan becomes the Your chat list and a preview thread whose first bubble is the opening line. Keep / Next walks the list.
4. **Look** — tone / length chips and the bottom-bar "they send" options, always previewed.

Advanced work (custom model API, training machine, custom code, interaction style, a one-to-one Speaking Coach copy) stays reachable from the same list, one row at a time, the way GPT Configure, Voiceflow tools, Typebot integration blocks, Intercom Procedures, and ElevenLabs / Vapi model settings keep depth off the first screen.
