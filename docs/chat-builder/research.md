# Conversational builders, compared

> **Label: Reference.** Founder-Approved: Artur, 17 November 2026, full-day goal, research the conversational builders. Sources are the public pages named below. The Presentation Builder described for this pass (Brief, Plan, Slides, Look, versions, undo, orange quotes) is not in this repository; the flow below follows that description.

## What was compared

| Product | How you build | Navigation | What to copy | What to leave |
| --- | --- | --- | --- | --- |
| OpenAI GPT builder | Create is a chat that fills a form. Configure is the form. [Help Center](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts), [Simon Willison, 15 Nov 2023](https://simonwillison.net/2023/Nov/15/gpts/) | Two tabs, easy to confuse. A usability review says the two panes and the two names fight each other. [Whitespace](https://www.whitespace.ch/insights/gpts-usability-review/) | One conversation that writes the config. Suggested replies. | A second form beside the chat. Two names for the same thing. |
| Claude Projects | A project is instructions plus files, edited as fields, not a chat that builds itself. | One page of settings. | A stable place the result lives. | No step list, no versions. |
| Character.ai | A character is a form: name, greeting, definition. | One long form. | The greeting as the first thing people hear. | No undo of a step, no binary walk. |
| Poe | A bot is a prompt plus a model picker. | Short form. | Pick the model in one place. | No conversation, no versions. |
| Voiceflow / Botpress | A canvas of blocks. | Powerful and dense. | The list of steps is the product. | The canvas is too much for a 12-year-old. |
| Typebot / Landbot | A flow of bubbles you drag. | Visual, still a builder's tool. | One question per bubble. | Drag-the-graph as the only way. |
| Gamma | A chat that turns a prompt into a deck, then you edit slides. | Prompt, then the result. | Talk first, then see the thing. | Little structure before the result. |
| The deck flow this pass copies | Stepper Brief, Plan, Slides, Look. Versions you can undo. Orange quotes you can tap ("the first one", "done"). Numbered cards. A reorderable plan. One composer: mic, text, send. A result card with two buttons. | Four names, one place to type, the list always there. | All of that, with two taps only. | A second composer. A form that repeats the chat. |

## The pattern we take

Talk writes the same config the table already shows. The table is Configure. The talk is Create. One of them is on screen. Undo restores a version. "Done" may finish early. "See the list" is always there.
